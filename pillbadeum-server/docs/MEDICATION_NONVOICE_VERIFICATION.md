# 복약지도 음성 제외 검증 결과

검증일: 2026-10-20. 기준 커밋 a449800 이후 알림·구독 실제 MySQL 통합 테스트 4개를 보강했다.
Live·단발 음성 테스트는 전부 제외했으며 OpenAI 호출은 하지 않았다. 복약 완료 체크는 구현 범위에 없다.

## 결과

| 항목 | 결과 |
| --- | --- |
| 음성 제외 Java 테스트 | 103개 통과, 실패 0, 제외 0 |
| 실제 8080 서버 읽기 전용 HTTP 검사 | 13개 통과, 실패 0, 제외 0 |
| 실행 파일 bootJar | 통과 |
| 사용자 DB 03 적용 상태 | 직접 입력 이름·NULL 허용·프로필/성분 컬럼·알림 표·시행 중 알림 약관 확인 |
| 사용자 데이터 변경 | 없음. 실제 서버에서는 로그인과 조회·오류·CORS 검사만 실행 |

변경 테스트는 작업 폴더의 별도 datadir와 13307 포트로 실행한 임시 MySQL 8.0.46의 pill_test에서 수행했다.
테스트가 생성한 합성 회원·약관·프로필·약·구독 자료만 사용했고 사용자 DB로 연결하지 않았다. 검증 후 임시 MySQL은 종료했다.

## 이번 결과의 범위

- 실제 브라우저 PushSubscription 발급·서비스 워커 알림 수신·클릭 이동은 미검증이다. 푸시 발송 단위 테스트는 로컬 HTTP 서버를 사용했고 DB 통합 테스트는 WebPushSender를 대체해 외부 전송을 차단했다.
- 실제 배포 서버의 환경 변수·DB 권한·프론트 출처 설정은 별도 환경에서 확인해야 한다.
- 음성·Live와 다른 담당자의 대화·이미지·Qdrant 기능은 이번 검사 대상이 아니다.

추가한 재현 테스트: src/test/java/org/semiproject/pillbadeumserver/medication/service/MedicationNotificationFlowMySqlTests.java.
실제 DB 테스트는 MYSQL_TEST_URL로 전용 pill_test를 지정해야 실행된다. 음성 제외 실행에서는 테스트 필터로 이름에 Live/Voice가 들어가는 테스트를 모두 제외했다.
