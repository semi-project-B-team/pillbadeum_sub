“오늘부터 이틀 타이레놀”처럼 말하면 빠진 항목을 기본 설정으로 채운 일정을 제안해요. “응”이면 저장하고, “저녁에만”처럼 바꿀 수도 있어요. “알아서 저장해”라고 맡기면 바로 저장해요. “엄마 타이레놀 일정 삭제해줘”로 일정을 지우거나 “그만 먹을래”로 오늘까지만 남길 수도 있어요.

토큰은 이 화면 메모리에서만 사용해요. OpenAI API 키는 입력하지 마세요.

실제 OpenAI 세션을 시작하면 사용 요금이 발생해요. 이 화면은 AI가 생성하는 음성을 재생해요. 대화는 최대 1분이며 등록·삭제·그만 먹기 완료 안내 후 자동 종료돼요. 입력한 프로필·약은 로그인 회원 소유여야 해요. 내 약 ID를 비우면 “오늘부터 일주일 혈압약”처럼 말한 이름으로 등록할 수 있어요.
