## 적용

- 기존 SQL01·03~10 적용 DB에는 `sql/11_DRUG_INGREDIENT_LENGTH.sql`을 명시적으로 실행하고 ingredient_patch_status=READY를 확인한 뒤 서버를 갱신함. 후속 설치 정리로 새 DB는 최신01만 사용하며 샘플02는 현재 컬럼명에 맞춤. 기존03~11 패치는 보존함.
- 환경변수 기본값은 `PILL_TIMEOUT_MS=85000`, `PRESCRIPTION_OCR_TIMEOUT_MS=60000`, `OPENAI_PERMIT_TIMEOUT_MS=10000`, `PUBLIC_DATA_PERMIT_TIMEOUT_MS=10000`임. 새 API 키는 필요하지 않음.
- 혼합 저장 JSON·실패/사진 정리 경계는 [사진 계약](PHOTO_REGISTRATION.md), 낱알의 기존 비교/선택 정책은 [낱알 v1](PILL_IDENTIFICATION.md)이 기준임. BUG-017의6개 이상 선택 금지와 단일 JVM 정책은 변경하지 않음.
- 사진의 시간 예산은 업로드·DB·프런트/프록시를 포함한 절대 응답 보장이 아님. 외부 제공자가 이미 시작한 계산의 중단까지 보장하지 않음.
- 검증은 실제 MySQL/Qdrant·로그인/JWT/HTTP와 로컬 합성 공급자를 사용함. 실제 유료 OCR·공공데이터·사용자DB·브라우저 수용 검증을 이번 실행 결과로 대체하지 않음.
